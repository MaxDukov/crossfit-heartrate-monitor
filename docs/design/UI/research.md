# Исследование UI/UX для монитора пульса CF-Monitor

> Дата: 25.07.2026. Основано на анализе конкурентов, кросс-индустриальных паттернов и теории дизайна для TV.

---

## 1. Кросс-индустриальные паттерны карточных сеток

Сетка карточек с именами и метриками — не уникальна для фитнеса. Аналогичные задачи решают в медицине, автоспорте, финансах, киберспорте и операционных центрах.

### 1.1. Медицинские мониторы (Philips IntelliVue, GE CARESCAPE)

- **Тёмный фон + цветные waveform-трассы** — HR традиционно зелёный, SpO2 синий, давление красный
- **Крупные числовые плитки + мини-тренд (silhouette)** — рядом с числом компактная кривая за 30 мин
- **Эскалация тревог:** advisory (жёлтый, медленно мигает) → warning (красный, быстрее) → alarm (красный + звук)
- **Trend arrows** (вверх/вниз/стабильно) рядом с числом
- **Применение к CF-Monitor:** пульсирующая красная рамка при зоне 4 > N секунд; тренд-стрелка рядом с BPM; силуэт-график уже реализован

### 1.2. Формула 1: телеметрия и руль-дашборд

- **RPM LED-bar** — горизонтальный ряд светодиодов, загорается зелёный → жёлтый → синий → красный по мере набора оборотов
- **Glanceability** — вся критичная информация считывается за <0.5 сек одним взглядом
- **Дельты** — отклонения показаны зелёным/красным цветом
- **Применение:** zone-bar (сегментированный индикатор зон) читается с расстояния быстрее, чем спидометр со стрелкой

### 1.3. Терминалы фондовых рынков (Bloomberg Terminal)

- **Фирменный чёрный фон** — снижает усталость глаз при 8-часовом слежении
- **Launchpad-компоненты** — постоянные мини-панели, каждая показывает один набор данных
- **Цветовое кодирование по категории** — функциональные «жёлтые клавиши»
- **Густая плотность + иерархия** — числовые значения крупнее меток, выравнивание по сетке
- **Применение:** настраиваемые пресеты раскладки под разные классы (WOD vs Open gym); плотная, но читаемая композиция

### 1.4. Киберспортивные HUD

- **HP-бары** — цветные полосы здоровья/маны, меняют цвет при порогах
- **Cooldown-таймеры** — кольцевые/линейные прогресс-индикаторы
- **Compact status panels** — тройное кодирование: иконка + цвет + число
- **Применение:** countdown для интервалов WoD; иконки зон для цветовой избыточности

### 1.5. NOC / Call-центры / Operations dashboards

- **Сетка статус-плиток** — green=OK, red=alert, amber=warning, grey=офлайн
- **Сортировка по критичности** — проблемные плитки всплывают наверх
- **Ghost-карточки** для пропавших датчиков — серая плитка с именем + «нет сигнала»
- **Применение:** режим тренера с автосортировкой по усилию; ghost-карточки для отвалившихся датчиков

## 2. Теория цвета для больших TV (10-foot UI)

### 2.1. Контраст (WCAG)

| Уровень | Текст | Контраст |
|---|---|---|
| AA (обычный) | <18pt | >= 4.5:1 |
| AA (крупный) | >=18pt или >=14pt жирный | >= 3:1 |
| AAA | любой | >= 7:1 |

**Для TV на расстоянии 3 м:** целите в **7:1+ для критичных чисел** (BPM). Дистанция снижает воспринимаемый контраст.

Источник: https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html

### 2.2. Практика для TV

- Избегайте чистого `#000` и чистых `#FFFFFF` — на TV они пересвечиваются
- Фон: тёмный серый `#0A0E14`...`#0F1620` вместо `#000000`
- Акценты: насыщенные, но не максимальные RGB
- **Overscan:** держите критичный контент в safe area (5% отступ от краёв)
- Уменьшите яркость фона карточки, поднимите акценты

### 2.3. Дальтоники (WCAG 1.4.1)

~8% мужчин имеют нарушения цветового зрения. Красный на чёрном проблемен для протанопов.

**Решение:** не кодируйте состояние **только цветом** — добавьте:
- Иконки (♥ в разных стилях для разных зон)
- Паттерны (сплошная / полосатая / точечная заливка)
- Текстовые метки («ВЫСОКАЯ», «КРИТИЧ.»)

### 2.4. Colorblind-safe палитра (Okabe-Ito)

| Цвет | Hex | Зона |
|---|---|---|
| Оранжевый | `#E69F00` | Зона 3 |
| Небесно-голубой | `#56B4E9` | Зона 1 |
| Зелёный | `#009E73` | Зона 2 |
| Жёлтый | `#F0E442` | Зона 3 (alt) |
| Синий | `#0072B2` | Зона 1 (alt) |
| Красный | `#D55E00` | Зона 4 |

## 3. Типографика для просмотра на расстоянии

### 3.1. Эмпирическое правило

Минимальный читаемый размер = `1/200 расстояния просмотра` (мм).
Для 3 м → ~15 мм на экране → ~50px эквивалент на 55" TV.

**Минимум любого текста на TV: 24px.**

### 3.2. Рекомендуемая типографическая шкала для карточки

| Элемент | Минимум | Оптимально | Примечание |
|---|---|---|---|
| BPM (главное число) | 96px | 120-160px | Читается с 5 м |
| Имя спортсмена | 28px | 32-40px | Жирный |
| Калории | 24px | 28-36px | Вторичный приоритет |
| % от max HR | 24px | 28-32px | Рядом с BPM |
| Название зоны | 22px | 26px | Дублируется цветом |
| Подписи (время) | 20px | 24px | Вторичные |
| Оси/легенда графика | 16px | 18-20px | Минимально читаемое |

### 3.3. Шрифты

- **Геометрический sans-serif** с высокой x-height: Inter, Roboto, IBM Plex Sans, Manrope
- **Tabular figures** (`font-variant-numeric: tabular-nums`) — обязательно, чтобы цифры не «прыгали»
- **Вес:** BPM 700-800, имя 600, подписи 500. Не используйте <500 на TV
- Для моноширинного техно-стиля: JetBrains Mono, Roboto Mono

## 4. Математика сетки на 16:9 TV

Аспект карточки = `(W/cols) : (H/rows)` при экране 16:9:

| Кол-во | Grid | Аспект карточки | Оценка |
|---|---|---|---|
| 4 | 2x2 | 16:9 (landscape) | Отлично — широкие карточки |
| 8 | 4x2 | ~1:1 (квадрат) | Хорошо — вертикальный layout |
| 8 | 3x3 (-1 центр) | смешанный | Дырка в центре — плохо |
| 12 | 4x3 | 4:3 | Хорошо |
| 16 | 4x4 | 16:9 (мелкие) | Только статус: имя+BPM+цвет |
| 16 | 8x2 | узкие полосы | Плохо для карточек |

### 4.1. Рекомендуемый switch

| n | Grid | Примечание |
|---|---|---|
| 1 | 1x1 | Full screen |
| 2 | 2x1 | Горизонтальный ряд |
| 3 | 3x1 | Горизонтальный ряд |
| 4 | 2x2 | Квадрат |
| 5-6 | 3x2 | Равномерно |
| 7-8 | 4x2 | Равномерно |

### 4.2. Интервалы

- Gap между карточками: 8-12px на TV
- Внутренний padding: 16-24px
- Container Queries (cqw) — industry-leading подход (конкуренты фиксируют размеры)

## 5. Рекомендации по зонной палитре

### 5.1. Принцип

- Фон карточки = зон-цвет с opacity 0.15-0.30
- Текст BPM = **всегда белый/почти-белый** для контраста
- Зон-цвет — в индикаторах (бар, кант, glow), не в основном тексте
- Тройное кодирование критичных состояний: цвет + форма/иконка + положение

### 5.2. Отраслевой стандарт — 5 зон (не 4)

| Зона | % max HR | Название | Цвет |
|---|---|---|---|
| 1 (Rest) | <50% | Восстановление | Серый `#9CA3AF` |
| 2 (Warm) | 50-60% | Лёгкая | Синий `#3B82F6` |
| 3 (Fatburn) | 60-80% | Умеренная | Зелёный `#22C55E` / `#0A8A06` |
| 4 (High) | 80-100% | Высокая | Янтарный `#EAB308` |
| 5 (Critical) | >100% | Критическая | Красный `#EF4444` / `#DC2626` |

### 5.3. Дополнительные зон-индикаторы

- **Segmented zone bar (RPM-LED style)** — горизонтальный бар из 5 сегментов
- **Цветной кант/тень** — `box-shadow: 0 0 24px <zone-color>` для зоны 5
- **Миксовать НЕ надо:** зона-цвет фона + зона-цвет текста BPM создают контраст-конфликт
